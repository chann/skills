description: Protect a supported local coding-agent session with HOL Guard before risky tool execution.
---

Use the **hol-guard** skill to detect the exact supported local harness, bootstrap
and install HOL Guard, prove the protected launch path with a dry run and
harness-specific doctor check, then start the guarded session.

Do not guess a harness identifier and do not fall back to an unprotected agent
when Guard denies, requires review, errors, times out, or cannot prove the
installation is healthy.
