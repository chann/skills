# AI 슬롭 용어 사전

교체는 항상 문맥을 따른다. 아래 대안은 출발점이지 기계적 치환표가 아니다.
사전에 없는 용어는 SKILL.md의 3단 판별을 통과할 때만 교체한다.

## 1. 직역·음차 개념어

| 용어 | 어색한 이유 | 자연스러운 방향 | 전 → 후 |
| --- | --- | --- | --- |
| 계약 (contract) | 테스트·API 문맥의 contract를 법률 용어로 직역 | 약속된 동작, 스펙 | "이 테스트는 API의 계약을 고정한다" → "이 테스트는 API가 약속한 동작이 달라지지 않는지 확인한다" |
| 엔벨로프 (envelope) | 일회성 음차, 업계에서 쓰지 않음 | 응답 형식, 공통 응답 틀 | "응답 엔벨로프를 통일한다" → "응답 형식을 통일한다" |
| 패리티 (parity) | feature parity의 음차 | 똑같이 동작, 기능 차이 없음 | "두 구현의 패리티를 유지한다" → "두 구현이 똑같이 동작하게 맞춘다" |
| 직교/직교성 (orthogonal) | 수학 은유의 직역 | 서로 독립적, 서로 영향 없음 | "두 설정은 직교한다" → "두 설정은 서로 영향을 주지 않는다" |
| 표면/표면적 (surface) | API surface의 직역 | 외부에 노출되는 부분, 쓰이는 범위 | "API 표면을 줄인다" → "외부에 노출되는 API를 줄인다" |
| 시맨틱 (semantics) | 굳은 전문 용어가 아닌 문맥에서 남용 | 의미, 동작 방식 | "시맨틱이 달라진다" → "의미가 달라진다" |
| 오케스트레이션 (orchestration) | 일반 산문에서 남용 (인프라 용어 문맥은 보존) | 조율, 전체 흐름 관리 | "여러 단계를 오케스트레이션한다" → "여러 단계를 조율한다" |
| 캐노니컬 (canonical) | 음차 남용 | 기준이 되는, 정본 | "캐노니컬한 경로" → "기준 경로" |
| 레버리지 (leverage) | 동사 leverage의 음차·직역 | ~를 써서, ~로 | "기존 코드를 레버리지하여" → "기존 코드를 써서" |
| 정렬 (align) | align의 직역 (자료 정렬 sort 문맥은 보존) | 맞추다, 합의하다 | "팀과 방향을 정렬한다" → "팀과 방향을 맞춘다" |
| 인사이트 (insight) | 남용 | 배운 점, 시사점 | "인사이트를 도출했다" → "배운 점을 정리했다" |
| 강건성/견고성 (robustness) | 논문투 직역 | 잘 버티는지, 안정성 | "강건성을 확보한다" → "이상 입력에도 잘 버티게 한다" |
| 원자적 (atomic) | DB·동시성 기술 문맥은 보존; 일반 산문에서 남용 | 한 번에, 중간에 끊기지 않게 | "설정을 원자적으로 바꾼다" → "설정을 한 번에 바꾼다" |
| 결정론적 (deterministic) | 기술 문맥은 보존; 일반 산문에서 남용 | 항상 같은 결과 | "결정론적으로 동작한다" → "언제 실행해도 같은 결과가 나온다" |

## 2. 내부 방법론 용어 노출

글쓴이의 프레임워크에서만 통하는 명칭·은유가 독자에게 그대로 새어 나온 경우.
독자가 그 어휘 체계에 동의한 적이 없다면 독자의 말로 바꾼다.

| 용어 | 자연스러운 방향 |
| --- | --- |
| 렌즈 (lens) | 검토 관점, 확인할 항목 |
| (열린) 노드 | 남은 결정, 미해결 항목 |
| 리프 (leaf) | 세부 항목, 마지막 갈래 |
| 프런티어 (frontier) | 남은 질문 목록 |
| 게이트 (gate) | 통과 조건 |
| 감사 (audit) | 점검, 확인 |
| 마감 기록 (closure record) | 정리한 결과, 결정 정리 |
| 아티팩트 (artifact) | 산출 파일, 결과물 |

전: 모든 렌즈 감사가 끝났고, 열린 노드가 없습니다. 마감 기록을 제시합니다.
후: 확인할 항목은 모두 살펴봤고, 남은 결정도 없습니다. 정리한 결과는 아래와
같습니다.

## 3. AI 상투 수식어

강력한, 원활한, 매끄러운 통합, 포괄적인, 혁신적인, 획기적인, 심층적인,
핵심적인 역할을 수행한다, ~를 보장합니다(남발), 잠재력을 발휘하다.
→ 구체적인 사실로 바꾸거나 지운다. "강력한 캐시" → "조회가 10배 빨라지는 캐시"
또는 그냥 "캐시".
